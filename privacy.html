Politique de confidentialité

Dernière mise à jour : 21 octobre 2026

Cette page explique quelles informations le portfolio traite, à quelles fins et comment vous pouvez gérer les données enregistrées dans votre navigateur. Elle concerne le portfolio d'Ababacar Souleymane Sane et son formulaire de contact.

1. Responsable et contact

Le responsable de ce portfolio est Ababacar Souleymane Sane, basé à Dakar, Sénégal. Pour toute question relative à cette politique ou à vos données, écrivez à

as.s9@zig.univ.sn.

2. Informations traitées

Lorsque vous remplissez le formulaire de contact, vous pouvez saisir votre nom, votre adresse e-mail, votre téléphone (facultatif), le sujet, un budget estimé et votre message. Le formulaire comprend également un contrôle anti-spam.

Le choix de langue est enregistré dans le stockage local de votre navigateur afin de le conserver entre les pages. Le site enregistre aussi localement des brouillons, un historique limité aux 50 derniers contacts et des événements techniques d'utilisation (par exemple, pages consultées ou actions sur le formulaire).

3. Finalités et envoi via WhatsApp

Les informations du formulaire servent à répondre à votre demande, discuter d'un projet ou préparer un devis. Lorsque vous soumettez le formulaire, le site prépare un message et ouvre WhatsApp. Vous gardez la main sur l'envoi effectif du message. Aucune base de données du portfolio ne reçoit le formulaire par cette action.

Si vous envoyez le message dans WhatsApp, Meta/WhatsApp traite alors les informations selon ses propres conditions et sa politique de confidentialité. Consultez ces documents avant l'envoi si vous souhaitez connaître les modalités de ce service.

4. Stockage et durée

Les brouillons, l'historique de contact, les événements d'utilisation et la préférence de langue sont conservés dans le stockage local de votre navigateur sur cet appareil. Ils ne sont pas automatiquement transmis à un serveur par le code du portfolio. Les brouillons et événements restent présents jusqu'à leur suppression ou l'effacement des données du site dans votre navigateur. L'historique conserve au maximum 50 entrées.

Pour supprimer ces données, effacez les données de site ou le stockage local associés à ce portfolio dans les paramètres de votre navigateur. Les données envoyées ensuite à WhatsApp sont soumises aux règles de ce service.

5. Services tiers et hébergement

Le portfolio charge des ressources techniques depuis des réseaux de diffusion de contenu tiers et affiche une carte intégrée de Google Maps sur la page Contact. L'ouverture de ces contenus peut transmettre des informations techniques, comme votre adresse IP et des informations sur votre navigateur, aux fournisseurs concernés. Les sites sont hébergés par Netlify, qui peut traiter des données techniques de connexion conformément à ses propres conditions.

Le code du portfolio ne met pas en place de cookies publicitaires ni de service d'analyse externe configuré. Certaines ressources intégrées ou certains services tiers peuvent toutefois utiliser leurs propres technologies de stockage ou de mesure, sous leur responsabilité.

6. Vos choix et vos droits

Vous pouvez choisir de ne pas remplir le formulaire, de ne pas envoyer le message préparé dans WhatsApp, ou de supprimer le stockage local depuis votre navigateur. Pour demander l'accès, la rectification ou la suppression d'informations que vous avez communiquées directement, contactez le responsable à l'adresse indiquée ci-dessus.

Cette page décrit les fonctionnalités actuellement présentes dans le portfolio et ne constitue pas un avis juridique. Elle doit être vérifiée et complétée par le responsable du site selon son statut, les services effectivement utilisés et les exigences légales applicables.
